# Playbook

One file per setup, e.g. `second_day_frontside.md`, `opening_range_break.md`.
Each file states: the idea in one sentence, the selection rules, the entry
trigger, the stop, management, and which rules are still discretionary or
UNGROUNDED. Source each setup (SMB module/video, Peter, or ledger promotion).

When a setup survives discovery and validation in the ledger, mark it
`status: validated` at the top and record the expectancy and its data span.
